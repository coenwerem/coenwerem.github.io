DexReach

GPU-Accelerated Whole-Body Dexterous Grasp and Manipulation Planning

Clinton Enwerem, John S. Baras, & Calin Belta

University of Maryland, College Park

Code (Coming Soon) Paper (Coming Soon) Simulation Demonstrations

DexReach is a GPU-accelerated Python package for whole-body dexterous grasp and manipulation planning, built on cuRobo. The videos show simulated grasping, pick-and-place, object reorientation, and bimanual manipulation across several arm–hand platforms.
