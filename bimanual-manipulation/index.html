Coordinated Manipulation Through Sustained Contact

Dexterous bimanual manipulation requires coordinated motion and sustained contact as objects move, interact, and are released. We study articulated door opening, part insertion, and constrained object relocation using the A7-L6 bimanual robot manipulator. The demonstrations below present task execution in MuJoCo. Door opening requires motion consistent with the door’s hinge; insertion requires part–housing alignment and housing support; constrained relocation requires clearing a passive flap before transferring the object. The three examples emphasize how the robot coordinates object motion with the surrounding mechanical constraints.
